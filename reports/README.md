# Reports

The application supports report generation from the admin area. Reports are intended to help administrators review product, order, and sales information.

## Supported Report Examples

- Products report
- Users report
- Orders report
- Sales report
- Category summary report
- Stock status report
- Price statistics report

## Export Formats

Supported formats:

- TXT
- CSV

Generated files should be saved in the `exports/` directory. Example report files are stored in `reports/examples/`.
